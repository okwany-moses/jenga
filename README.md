# JengaFlow

Automated Lead Generation & Business Management Systems tailored for Kenyan SMEs.

## Core Capabilities
- **Lead Generation Pipelines**: Custom inbound engines to capture and route prospective clients.
- **Database Infrastructure**: Secure platforms using PostgreSQL for robust data management.
- **Operations Automation**: Lightweight CRM portals built with modern UIs to eliminate manual tasks.

## Tech Stack
- HTML5, Tailwind CSS, FontAwesome, Web3Forms.
